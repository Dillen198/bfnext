# What this repo's DCSServerBot plugins and extensions need on top of
# DCSServerBot's own requirements (its requirements.txt already brings
# discord.py, aiohttp, fastapi, psutil, ruamel.yaml, matplotlib and Pillow).
# Install into the bot's venv, then restart the bot:
#
#   <bot>\.venv\Scripts\python -m pip install -r requirements-plugins.txt
#
# (DCSServerBot's own installer puts its venv at %USERPROFILE%\.dcssb by
# default.) Every entry is optional at run time -- a plugin that misses one
# logs a warning and turns the feature off -- so this file is not installed
# automatically. Bump the pins deliberately and test on a box.
